## What an agent needs to know first

Anixter publishes NO machine-readable contract. There is no OpenAPI, no AsyncAPI, no
GraphQL SDL, no WSDL, no Postman collection, no MCP server and no A2A agent card at any
host in the Anixter or Wesco family. Every /.well-known/ path on www.anixter.com,
anixter.com, www.wesco.com and wesco.com answers HTTP 403 behind a Cloudflare managed
challenge; every /.well-known/ path on api.wesco.com answers 404.

An API management platform IS in place. api.wesco.com resolves to
api-wesco.lb.anypointdns.net, a MuleSoft Anypoint Platform dedicated load balancer, and
the Anypoint Exchange organization domain "anixter" exists with its public portal switched
on — but it publishes zero public assets. The API program is real; the public catalog is
empty. Integration is arranged through a commercial conversation, not self-serve signup.

## Integration surface (documented in prose, not in a contract)

- EDI — electronic exchange of order information, purchase orders, invoices and shipping
  notices with Anixter. Transaction set numbers, standard version and implementation guide
  are not published.
- Punchout catalogs — access to Anixter's product catalog from inside a customer's
  procurement or eProcurement system. The wire protocol (cXML PunchOut, SAP OCI, Ariba) is
  not published.
- Flat file catalog delivery, custom invoicing, consolidated billing.

## What is NOT here, and why

will never author on a provider's behalf. No skills/, overlays/, errors/, scopes/,
authentication/ or data-model/: every one of those is derived from a contract, and there is
no contract to derive them from.
